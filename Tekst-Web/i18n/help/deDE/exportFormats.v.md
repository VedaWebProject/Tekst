# Exportformate

## JSON

Umfassende Exportdaten als JSON - ein Format, das gut zur maschinellen Weiterverarbeitung geeignet ist.

## CSV

Tabellarischer Datenexport als kommagetrennte Werte - nützlich für Tabellenkalkulationsprogramme wie Excel oder die spätere Weiterverarbeitung.

## Tekst-JSONL

Spezieller JSONL-Export ([JSON Lines](https://jsonlines.org/)), der für den Re-Import in die Plattform geeignet ist.

Das JSON-Element in der ersten Zeile enthält Metadaten zur Ressource selbst, alle weiteren Zeilen enthalten jeweils ein Element mit den Daten zu jedem exportierten Inhalt.
