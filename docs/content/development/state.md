# State of Development

Tekst is currently in its open beta phase. The features initially planned by and for the [VedaWeb](https://vedaweb.uni-koeln.de/) project are implemented and available. As soon as the VedaWeb platform has test-driven the user management and collaboration features for some time, Tekst will be ready to leave beta.

You are very welcome to try and test Tekst or even use it for your own projects if you see fit. If you have any questions or suggestions or find any bugs, please [open an issue](https://github.com/VedaWebProject/Tekst/issues) or even [contribute](https://github.com/VedaWebProject/Tekst)!
